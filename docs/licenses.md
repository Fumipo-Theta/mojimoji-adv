## 取り込み予定のもの

### KanjiVG — 筆順データ（M4）

- **用途**: お手本表示・筆順アニメーション
- **ライセンス**: Creative Commons Attribution-Share Alike 3.0
- **収録**: ひらがな・カタカナ・漢字のストローク順 SVG
- **義務**:
  - **帰属表示が必要。** アプリ内（設定画面かクレジット画面）に KanjiVG と作者 Ulrich Apel への
    クレジットと CC BY-SA 3.0 へのリンクを明記すること
  - **Share Alike**: 派生させたデータを配布する場合、同じライセンスで公開する必要がある
    （パスを加工して再配布する場合は要注意。表示に使うだけなら影響は小さい）
- **入手**: https://kanjivg.tagaini.net/

### ETLCDB（産総研 ETL 文字データベース）— 学習データ（M6）

- **用途**: `TfjsCnnRecognizer` の学習データ（ETL7 ひらがな / ETL6 カタカナ / ETL8・ETL9 漢字）
- **ライセンス**: **登録制。非商用目的の登録ユーザーに限り無償。** 商用利用は個別交渉が必要
- **著作権**: 産業技術総合研究所（AIST）が保持
- **注意点**:
  - 利用前に登録フォームからの申請と利用条件への同意が必要
  - **データセット本体をこのリポジトリに含めてはいけない**（`.gitignore` 済み）
  - **学習済み重みの再配布可否は、着手時に利用条件を読み直して判断すること。**
    個人利用に留めるか、重みも配布しない前提にしておくのが安全
- **入手**: https://etlcdb.db.aist.go.jp/
